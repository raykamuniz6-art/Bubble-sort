# Projeto: Ordenação de Temperaturas com Bubble Sort

## 1. Sobre o projeto

Este projeto foi desenvolvido para a atividade avaliativa da disciplina Algoritmos e Pensamento Computacional, do Centro Universitário UDF.

O programa foi desenvolvido na linguagem C e utiliza o algoritmo Bubble Sort para organizar dez temperaturas em ordem crescente.

## 2. Objetivo

O objetivo do projeto é aplicar conceitos de lógica de programação, vetores, estruturas de repetição e estruturas condicionais por meio de um algoritmo de ordenação.

## 3. Situação-problema

No cotidiano, organizar temperaturas registradas pode facilitar a análise de dados climáticos, permitindo identificar os menores e maiores valores e comparar diferentes medições.

Para isso, desenvolvemos uma aplicação que recebe dez temperaturas informadas pelo usuário e organiza os valores em ordem crescente.

## 4. Funcionamento do programa

O programa solicita ao usuário dez temperaturas e apresenta os valores digitados antes da ordenação.

Em seguida, utiliza o algoritmo Bubble Sort para comparar elementos vizinhos. Quando um elemento é maior que o próximo, os valores trocam de posição.

Esse processo se repete até que todas as temperaturas estejam organizadas da menor para a maior.

Ao final, o programa apresenta as temperaturas ordenadas.

## 5. Algoritmo utilizado

### Bubble Sort

O Bubble Sort é um algoritmo de ordenação que compara elementos vizinhos de um vetor e troca suas posições quando estão fora da ordem desejada.

A cada passagem, os maiores valores vão sendo deslocados para o final do vetor, até que todos os elementos estejam ordenados.

Neste projeto, o algoritmo é utilizado para organizar as temperaturas em ordem crescente.

## 6. Tecnologias utilizadas

- Linguagem C.
- OnlineGDB para desenvolvimento e testes.
- GitHub para armazenar e compartilhar o código-fonte.

## 7. Como executar

1. Baixe o arquivo `bubble_sort.c`.
2. Abra o arquivo em um compilador C, como o OnlineGDB.
3. Selecione a linguagem C.
4. Execute o programa.
5. Digite as dez temperaturas solicitadas.
6. Confira os valores originais e o resultado ordenado.

## 8. Exemplo de execução

**Temperaturas informadas:**

32, 25, 29, 21, 30, 18, 27, 24, 35, 20.

**Resultado em ordem crescente:**

18, 20, 21, 24, 25, 27, 29, 30, 32, 35.
